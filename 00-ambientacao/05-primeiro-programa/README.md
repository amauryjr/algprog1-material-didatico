# 05 – Seu primeiro programa Python

Nesta etapa, criaremos, executaremos e modificaremos um primeiro programa.

## 1. Criar o arquivo

No VS Code, com a pasta `algoritmos-programacao` aberta:

1. Crie um novo arquivo.
2. Salve-o com o nome `hello.py`.
3. Digite o código abaixo.

## 2. Código inicial

```python
print("Olá, mundo!")
print("Estou começando a programar em Python.")
```

## 3. Executar o programa

Há duas formas simples:

**Pelo terminal integrado**

Com o terminal aberto na pasta que contém o arquivo, execute:

Windows:

```bash
python hello.py
```

Se necessário, tente `py hello.py`.

macOS ou Linux:

```bash
python3 hello.py
```

**Pelo VS Code**

Com o arquivo aberto, utilize o comando **Run Python File** (Executar arquivo Python), disponibilizado pela extensão Python.

## 4. Investigar o programa

Observe o código e responda:

1. Quantas instruções existem?
2. O que a função `print()` faz?
3. O que acontece se você trocar o texto da primeira instrução?
4. O que acontece se você acrescentar uma terceira instrução `print()`?

## 5. Modificar

Altere o programa para exibir:

- seu primeiro nome ou um apelido;
- o nome da disciplina;
- uma frase sobre o que espera aprender.

Não inclua informações pessoais que não queira tornar públicas.

## 6. Desafio

Crie um programa chamado `apresentacao.py` que exiba pelo menos três linhas de texto. Execute-o e confira se a saída corresponde ao que você planejou.
